# Kaiva OS · propuesta

Propuesta para ordenar el panel de Kaiva Studio por lo que importa: jerarquía, menú, flujos y movimiento.

- `index.html`: la propuesta, con pantallas vivas en un Mac.
- `investigacion.html`: lo que dicen los referentes (Few, Tufte, Nielsen Norman Group, Apple, Material, Emil Kowalski…), con sus fuentes.
- `app/`: el prototipo navegable (Ctrl K para buscar, G luego I para ir a Inicio).

Datos de ejemplo: no son las cifras reales del estudio.
